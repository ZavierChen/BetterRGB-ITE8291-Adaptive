# 已知问题

- 当前 HID 采用独占打开。BetterRGB 运行时，官方控制中心可能隐藏灯光页面或无法接管；退出 BetterRGB 并重启官方服务即可恢复。
- 应用没有代码签名，Windows SmartScreen、浏览器或网盘可能提示未知发布者，部分安全软件可能启发式误报。
- 仅在一台苍龙 16 X Pro 实机完成完整验证，其他同方/ITE8291 机型即使 VID 相同也可能有不同键位偏移。
- 日志和配置写在 EXE 同目录；若放入无写权限目录，配置保存和日志会失败。
- 快速模式切换、电源切换或设备重枚举时可能短暂黑灯，重连后会恢复当前模式。
- WMI Fn 事件依赖厂商 ACPI/WMI 实现，换机型或卸载厂商基础驱动后可能失效。
- Fn+Space 当前未适配，请通过程序界面切换灯效。
- 多个动态灯效叠加 Touch Bar 指标时会增加 HID 写入和 CPU 唤醒，电池模式应使用较低 FPS/亮度。
- 未实现共享 HID 模式。若厂商服务周期性重开设备，可能出现抢占或灯效闪烁。
