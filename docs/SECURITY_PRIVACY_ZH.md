# 安全与隐私

- 应用不联网，没有遥测、账号、API 密钥或自动更新模块。
- 应用读取 HID 设备信息、键盘原始输入/WMI Fn 事件、电源、音量及本机性能计数器，用于灯效与快捷键。
- 日志保存在本地 EXE 目录，可能包含完整 HID 设备路径和线程时序；对外提交前必须脱敏。
- 应用不安装内核驱动，但独占打开 RGB HID 接口会影响官方控制软件。
- 计划任务用于登录后自启，不用于提升或维持隐藏持久化；卸载时应删除任务。
- 当前二进制未签名。接收方应以包外发布的 SHA-256 校验并从可信渠道获取，不应仅依据文件名判断真伪。
- 禁止将 HID 匹配放宽到所有 `VID_048D` 设备；向错误设备发送厂商 Feature report 可能产生未知行为。
