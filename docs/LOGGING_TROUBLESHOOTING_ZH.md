# 日志与故障排查

## 文件位置

程序在 EXE 同目录创建：

- `better_rgb.cfg`：纯文本配置，可在程序退出后备份或删除以恢复默认。
- `rgb_engine_log.txt`：时间、线程号、设备枚举、重连、慢帧和模式切换日志。

交接包只含脱敏示例，不含用户真实配置、设备实例路径或运行日志。

## 常见问题

### 启动后无灯光

1. 退出官方控制中心并停止其灯光服务。
2. 查看日志是否找到 `VID=048D PID=600B` 和 `usage_page=0xFF03`。
3. 若显示 sharing violation，确认没有另一个 BetterRGB 实例或官方服务占用。
4. 若设备不存在，停止尝试，不要修改 PID 白名单硬发数据。

### 某些键不亮或位置错误

这是键位偏移映射问题的优先信号，不代表 LED 损坏。使用静态逐键测试定位偏移，重点检查左 Shift、Enter、空格和方向键；不要通过提高亮度/刷新率掩盖映射错误。

### 动画卡顿

查看 `send_frame SLOW`、重连和有效 FPS 日志。先降低目标 FPS、关闭高频指标叠加，再排除官方服务抢占。屏幕 300 Hz 与 RGB HID 帧率没有一一对应关系。

### Fn 无效

检查日志中的 `Fn hotkey WMI` 订阅状态；确认厂商 WMI/ACPI 组件仍在。RGB 主功能与 WMI 快捷键相互独立。

### 官方控制中心无法调灯

正常退出 BetterRGB，取消其计划任务自启，结束残留进程，然后重新启动厂商控制服务或重启系统。详见 `ROLLBACK_RECOVERY_ZH.md`。
