# 兼容性矩阵

| 项目 | 状态 | 证据/限制 |
|---|---|---|
| 机械革命苍龙 16 X Pro | 已验证 | 测试机完整运行动态灯效、Fn+F6/F7、配置和自启；Fn+Space 未适配 |
| 主板 CANGLONG Series-X6xR55xY | 已验证 | 实机 WMI/CIM 信息 |
| BIOS N.1.18MRO43 | 已验证 | 2026-01-29 版本 |
| ITE HID `048D:600B`, Usage Page `FF03`, MI_01 | 已验证 | 枚举日志和逐帧输出成功 |
| Windows 11 x64 10.0.26200 | 已验证 | 构建与运行测试环境 |
| Windows 10/其他 Windows 11 版本 | 待验证 | 使用的 API 理论可用，未做本轮实测 |
| 其他 `048D:600B` 同方机型 | 实验性 | 必须验证键位映射、Usage Page 和 Fn WMI |
| 其他 ITE PID | 不支持/待适配 | 当前只对白名单路径打分，不保证协议相同 |
| 官方控制中心并行运行 | 不支持 | 独占 HID 设计，需二选一 |
| 无厂商 WMI/ACPI 服务 | 部分可用 | RGB 可工作，Fn 快捷键可能不可用 |
| Secure Boot | 可用 | 用户态未签名 EXE，不加载内核驱动 |

“已验证”只代表所列组合，不代表所有批次键盘、EC 或 BIOS 均一致。扩展兼容性时应保留失败即停止的白名单策略。
