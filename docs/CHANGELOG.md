# CHANGELOG

本记录根据历史安装包说明、EXE 版本资源、回滚目录、各版手册、配置字段差异、运行日志及 GitHub Release 交叉恢复。早期版本未全部建立 Git 标签，因此以下内容记录可验证的功能演进；标为“实验性构建”的功能不代表进入过最终公开版本。

## v3.6.1 — 音量 Bar 自动切换修复

- 修复指标线程只在启动时绑定一次默认播放设备的问题；开机音频初始化、驱动重载或播放设备切换后不再停留在旧端点。
- 每秒复核 Windows 默认播放端点 ID，变化后自动释放旧接口并重新绑定音量与播放峰值接口，无需重启 BetterRGB。
- 保持 0.4% 音量变化阈值和 1.8 秒临时音量 Bar；超时后恢复插电或电池方案原先配置的指标。
- 增加端点重绑定、临时覆盖开始和结束日志，方便现场判断是系统音量事件还是 RGB 输出问题。
- 版本资源、构建脚本、二进制校验、项目主页和实机测试记录同步到 3.6.1。

## v3.6.0 — 三通道白色光谱校准

- 以“原始满亮度纯白 → 选择肉眼实际观察颜色 → 计算 R/G/B 独立增益”完成白平衡校准。
- 在 sRGB 转线性光后，以最弱通道为基准，只衰减过强通道，避免高光裁切。
- 校准期间绕过旧校正、亮度限制和空闲熄灯，确保观察的是原始白色输出。
- 校正作用于最终 HID 帧出口，覆盖静态灯、动画、屏幕氛围灯、顶行 Bar 和过渡效果。
- 校准结果以 `whiteObservedColor`、`whiteGainR/G/B` 写入 `better_rgb.cfg`；支持取消、异常颜色保护和一键重置。

## v3.5.0 — 单轴白平衡（过渡版本）

- 增加范围 `-40..40` 的全局“洋红—绿色”滑块，用于缓解白色偏紫。
- 在最终 HID 帧出口统一应用校正，覆盖静态灯、动画、屏幕氛围灯和顶行 Bar。
- 校正值曾以 `whiteBalanceGreen` 保存；随后被 v3.6.0 的三通道光谱校准取代。

## v3.4.5 — 首个公开 GitHub 版本

- 汇总随机呼吸、涟漪、彩虹、流沙、电流、触控电流、同步辨色、星光、雨滴和闪电等灯效。
- 星光、雨滴和闪电使用连续亮度包络；收窄闪电横向扩散，减少突亮突灭和视觉过粗。
- 移除体验不达标的电流穿心和外部游戏 FPS 采集路径；界面 FPS 只表示 RGB 引擎调度帧率。
- 增加独占 HID、断线重连、慢帧记录、有效 FPS 自适应降速及稳定后逐步恢复。
- 参数和帮助只在对应灯效或指标选中时显示。
- 完成源码、中文技术文档、第三方许可、可复现 LLVM-MinGW 构建脚本、二进制验证和 GitHub Release。

## v3.4.3–v3.4.4 — 未发现独立交付物

- 现存备份中没有可单独验证的 3.4.3 或 3.4.4 EXE、手册或标签。
- 相关稳定性整理统一记入 v3.4.5，不虚构独立改动。

## v3.4.2 — FrameView / PresentMon 兼容探索（实验性构建）

- 继续尝试 FrameView SDK 与 PresentMon 回退路径、诊断管道、超时和重连处理。
- 因不同权限模型和游戏环境下结果不稳定，最终发布构建用编译开关排除采集线程，并自动清理遗留工具和进程。

## v3.4.1 — PresentMon 游戏 FPS 指示（实验性构建）

- 撤下心电原型配置，转向按前台进程采集真实呈现帧率。
- 打包并测试 PresentMon，增加插电/电池的 FPS 量程配置、进程切换和旧会话清理。
- 运行记录出现 ETW 会话冲突、权限差异、CSV 头超时和不同游戏兼容性问题。

## v3.4.0 — 早启动服务与心电/FPS 原型（实验性构建）

- 实验 `BetterRGBBoot` 自动服务：LocalSystem 在登录前独占 HID，随后通过命名事件把最后一帧无黑屏交接给用户会话 GUI。
- 服务完成两轮无重启验证，并配套一键回滚到 v3.3.0；该路径未作为最终公开安装方式保留。
- 增加心电/电流穿心原型和顶行 FPS 上限配置，开始评估实时游戏帧率显示。

## v3.3.0 — 双蛇漩涡与连续时长

- 将漩涡路径扩展为两条对角蛇沿螺旋轨迹同步爬行的双蛇动画。
- 过渡时间改为 0.2–3.0 秒、0.1 秒步进的连续滑杆。
- 过渡统一作用于主灯效与顶行 Bar 的最终合成帧，不改写流沙、电流或同步辨色本身。

## v3.2.1 — 手动灯效过渡

- “停止主灯效”使用逆向过渡熄灭主键区，从空白重新选择灯效时正向点亮。
- 普通灯效之间切换不强制黑屏，顶行 Bar 可持续显示。

## v3.2.0 — 统一电源过渡

- 启动、退出、无输入休眠和输入唤醒共用同一套物理键位遮罩过渡。
- 增加全局渐变、中心/四边/上下左右涟漪及顺逆时针漩涡。
- 初版提供 0.4/0.8/1.1/1.4 秒四档时长；退出和休眠自动使用点亮动画的逆过程。

## v3.1.0 — 横向分页界面

- 界面拆分为“灯效、插电方案、电池方案、顶行 Bar、程序设置”五页。
- 插电与电池方案可直接独立编辑；当前方案即时应用，另一套只保存。
- 顶行 Bar 两套电源配置并排显示，并修正暗色分页导航、标签间距和条件参数布局。

## v3.0.2 — 屏幕映射与指标颜色统一

- 改进同步辨色的屏幕到物理键位映射、模糊和响应参数。
- 音量、麦克风、CPU、GPU 统一为“长度表示数值、整段颜色表示区间”的显示方式。

## v3.0.1 — 指标色彩与音频 RGB

- 电量改为整段同色，低电量红、高电量绿并连续过渡。
- 播放音频增加三色线性光闭环渐变，插电和电池分别保存三组音频颜色。
- 修正顶行颜色方向和配置持久化。

## v3.0.0 — 顶行信息 Bar 与同步辨色

- `Esc`、`F1`–`F12` 和右侧功能键可独立显示电池、系统音量、麦克风、CPU、GPU 或播放音频强度。
- 插电/电池分别保存 Bar 开关、类型、方向和颜色，不依赖主灯效自动切换开关。
- 增加同步辨色：按键盘物理位置对屏幕降采样，在线性光空间模糊并做帧间平滑；画面只保存在内存中。
- 增加默认音频端点失效后的接口重试，并保持主灯效停止时 Bar 可独立运行。

## v2.4.4 — 字符区行映射收尾

- 继续校正字符区、方向区和特殊宽键的行归属，使所有灯效共享同一套正确底层映射。

## v2.4.3 — Enter / 反斜杠灯位修正

- 反斜杠改用小键盘 789 行对应 LED 槽。
- 宽 Enter 同时驱动小键盘 456 行的两个 LED 槽，修复宽键缺灯。

## v2.4.2 — 物理行视觉修正

- 修正动画使用的视觉行定义，使流沙、电流等效果与实际键盘行排列一致。

## v2.4.1 — 电流平滑

- 为电流光头、拖尾和跨键移动增加覆盖采样、余辉与帧间插值，减少跳格和硬边。

## v2.4.0 — 流沙、电流与触控电流

- 增加三色流沙，可调三色、速度和空间尺度。
- 增加逐物理键行推进的电流，可调三色、速度和光段宽度。
- 增加按键触发、沿所在物理行双向扩散的触控电流。

## v2.3.0 — 近板载接管与平滑退出

- 登录任务提高启动优先级并增加首次失败重试，缩短登录后原厂灯效残留时间。
- 增加关机、注销和普通退出前的平滑渐暗处理。
- 继续坚持用户态接管；未发现安全、公开的板载持久化协议，因此不写 EC 或固件。

## v2.2.0 — 全彩覆盖与彩虹速度

- 完成更完整的全键盘 RGB 输出路径。
- 增加彩虹速度配置 `rainbowSpeed`，使彩色流动速度可调。

## v2.1.0 — Fn 亮度与键位覆盖

- 通过原机 ACPI/WMI 热键事件接入 `Fn+F6/F7`，按 0/25/50/75/100% 调整亮度，不安装驱动、不使用全局键盘钩子。
- 快捷键同步界面滑杆并保存到当前插电或电池方案。
- 继续校正物理键位布局和全键盘 RGB 覆盖；`Fn+Space` 因本机不向 Windows 上报对应事件而保持未适配。

## v2.0.0 — 双电源方案与交互灯效

- 插电与电池分别保存灯效、亮度和目标 FPS，并支持插拔电源自动切换。
- 增加随机多色呼吸：每次呼吸到最低点后平滑换色。
- 增加触碰涟漪：以按键为圆心扩散，可选固定色或随机色。
- 增加 1/5/10/30 分钟无输入熄灯及输入恢复。

## v1.0 — 首个苍龙 16 Pro 中文增强交付

- 增加简体中文界面和一键本机安装包。
- 确认目标接口为 `VID_048D&PID_600B`、Usage Page `0xFF03`、MI_01，并在苍龙 16 Pro / Windows 11 x64 上验证。
- 修正苍龙 16 Pro 的 Enter、左 Shift 等灯位兼容映射。
- 增加 15–60 FPS 可调帧率、传输异常自适应回退，以及更稳妥的进程和灯效线程优先级。
- 明确独占 HID、退出后恢复原厂控制、SmartScreen 未签名提示和硬件断电恢复步骤。

## 上游基线

- 项目早期基础来自 EpicYamo / TheYamo 的 `Better-RGB-for-Tongfang_ITE8291`，依据 MIT License 延续。
