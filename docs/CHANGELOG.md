# CHANGELOG

## 应用 3.6.0

- 以“纯白输出 → 完整光谱选择实测颜色 → 三通道逆向增益”替代一维绿—洋红滑块。
- 校准算法在 sRGB 转线性光后，以最弱通道为基准分别计算 R/G/B 增益，避免高光裁切。
- 校准过程中临时绕过旧校正和亮度限制，确保用户观察到的是原始满亮度白色。
- 增加校准取消保护、过暗颜色校验和一键重置。

## 应用 3.5.0

- 新增全局“洋红—绿色”白平衡滑块，范围 `-40..40`，用于校正键盘白色偏紫。
- 白平衡在最终 HID 帧出口统一应用，覆盖静态灯、动画、屏幕氛围灯和顶行 Bar。
- 校正值写入 `better_rgb.cfg` 的 `whiteBalanceGreen`；默认 `0` 保持旧版颜色不变。

## 交接包 v2.0 / 应用 3.4.5

- 增加插电与电池两套独立灯效、亮度、FPS 和 Touch Bar 配置。
- 增加随机多色呼吸、涟漪、彩虹、流沙、电流、触控电流、同步辨色等灯效。
- 增加星光、雨滴、闪电的连续亮度包络，减少单键突亮突灭。
- 收窄闪电横向扩散，避免视觉过粗。
- 增加启动、关闭、从空白恢复、停止和定时休眠过渡；过渡时间可调。
- 增加中心、边缘、上下左右及双蛇形漩涡路径过渡，中心定位以 J/K 附近为视觉原点。
- 增加无输入定时休眠与输入唤醒。
- 增加 Fn+F6/F7 亮度控制；Fn+Space 当前未适配。
- 增加电量、音量、麦克风、CPU、GPU、音频 Touch Bar 显示及音量临时覆盖。
- 参数和说明改为仅在对应效果/指标选中时显示。
- 移除体验不达标的电流穿心灯效。
- 增加独占 HID 打开、断线重连、慢帧记录和有效 FPS 自适应。
- 完成简体中文增强 UI 和配置持久化。
