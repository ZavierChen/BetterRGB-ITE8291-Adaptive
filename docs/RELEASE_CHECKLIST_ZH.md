# 发布检查清单

- [ ] 从干净输出目录执行 `build/build.ps1`。
- [ ] 第一方代码无编译警告，版本资源与文件名一致。
- [ ] 使用 `verify_binary.ps1` 记录大小、版本、签名和 SHA-256。
- [ ] 检查 PE 导入表，仅含预期 Windows 系统 DLL。
- [ ] 在空目录启动，确认配置/日志可创建、HID 可枚举、退出可恢复。
- [ ] 验证静态逐键映射、全部动态模式、Fn、电源切换、休眠和过渡。
- [ ] 验证退出后官方控制中心恢复。
- [ ] 包内不含 `.git`、对象文件、PDB、真实日志/配置、个人路径、密钥和证书。
- [ ] 包含许可、兼容性、风险、回滚和已知问题。
- [ ] ZIP 只有一个顶层目录，解压后按 `SHA256SUMS.txt` 复核。
- [ ] 对 EXE 和 ZIP 执行本机安全扫描；未签名状态明确披露。
- [ ] 发布 ZIP 的 SHA-256 通过独立渠道公布。
